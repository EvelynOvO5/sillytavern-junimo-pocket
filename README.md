# Junimo Pocket · 月亮谷手机

SillyTavern 悬浮手机扩展，保留原版 HTML 的像素风界面、农场装饰、日历卡片、任务详情弹窗与全屏分区地图。

## 0.8.0

- 桌面仅显示一行简短同步状态；详情与最近记录放到设置的折叠面板，不再推挤时钟与图标。设置重新设计为分组卡片。
- 支持 `--`、破折号、N/A 等未知价格写法；重生成与切换候选回复的提示词以被替换正文之前的状态为起点，明确补齐缺失NPC位置。
- 聊天输入框右侧 **➤** 只发气泡；下方工具栏的 **ϟ** 才触发回复。语音、表情包在工具栏中。
- 表情包支持导入本地 PNG/JPG/WebP/GIF，填写名称与说明。图片存放在当前浏览器 IndexedDB，不随聊天存档导出；用户与 AI 都可发送库中的表情包。
- 设置中的“表情包视觉识别”默认关闭。关闭时只发送名称和说明；开启后相关图片会发给当前 API（需模型支持图片），也可在导入面板点“AI 识图填写说明”。

- 兼容省略年份、星期调序、未知价格与进度、人物别名和楼层后缀；额外系统角色单独提示，不阻断有效状态。列表存在无法解释的行时保留原列表，避免半份背包覆盖存档。
- 私聊与群聊共享按收发时间排列的近期记忆。角色只知道自己参与的聊天；上下文有长度上限，不等于无限记忆。
- 支持群聊引出角色私聊、私聊引出群消息，由当前参与者按合理动机选择；身份与目标经过校验，不自动递归对聊。
- 等待回复时显示动态“正在输入”，模拟语音回复显示“正在录制语音”。
- 输入栏麦克风按钮用于文字模拟语音：输入台词，＋暂存气泡，➤触发回复。双方的语音气泡显示波形、模拟时长和转文字，点击可收起文字。不录音、不访问麦克风、不生成真实音频。
- 聊天按人设和心情使用标点，不要求每条消息以句号结尾。

- 正文负责变量：每轮末尾用 `【手机状态】` 与 `【状态结束】` 包住文字摘要，例如 `位置：哈兰|邮局`、`好感：莱恩|25`、`时间：春季|1|1|06:20|晴`。空农田只写 `农田：无`，不列空格。旧 JSON 协议仍兼容。
- 首次变量块包括全部角色的初始地图位置，之后只更新移动角色，直接在原版地图标记头像。
- 农田区分 empty、seeded、growing、mature。未成熟作物不能写成剩余 0 天，未知天数用 null。变量缺失或无效时明确提示。
- 开局背包、动物、建筑、材料、种植为空，装饰图片仍保留。
- 强调每轮按故事耗时推进时间、按实际互动更新好感。私聊只允许当前角色，拦截其他角色署名台词。
- 聊天列表置顶全员邻里群、用户与莱恩莱尔的三人群；群聊逐条标记发言人头像和名字。
- ＋：立即形成气泡，不调用 API，可连续发送多条。➤：把当前输入及待回复气泡交给角色统一回复；失败保留气泡，可重试。首次进入显示使用说明。
- 设置中的“AI 重新整理变量（先预览）”读取最近正文和世界书，弹出可编辑文字摘要；取消不改状态，确认并校验通过才应用。正文变化时旧预览失效；应用前保留备份。
- 从灵动岛、状态栏或边框拖动，右上收起按钮在每个 App 内可用。

## 使用

从酒馆扩展管理更新本插件并刷新。打开月亮谷物语单角色聊天，开启手机设置中的“正文变量同步”，重新生成一轮正文让协议生效。旧正文没有变量块时不会使用 API 猜测。编辑、删除、切换正文后按快照回退。

首次升级到 0.5 会将旧版状态备份到本聊天元数据的 legacyBackup，采用空基线等待新的正文变量；手机聊天记录保留。

首次绑定只接受当前卡关联的世界书“⭐农民也要涩涩！”，之后跟随同一张卡的世界书，不混入全局世界书。手机聊天请求前读取最新内容。

API 设置在手机内：填写地址和 Key，拉取模型选择完整渠道名，保存多个命名预设并切换。HTTP 接口需勾选允许 HTTP，会明文传输 Key 和内容。预设 Key 存在当前浏览器 localStorage，同源脚本可访问；不进入 GitHub 或聊天存档导出。接口需允许浏览器跨域，503 表示所选服务或模型渠道暂不可用。

文字摘要使用固定栏目和分隔符，兼顾可读性与直接捕捉。变量协议降低误读，但生成模型仍可能写错，不是完整游戏规则引擎。行动是否执行及配方消耗以正文确认结果为准。

## 开发

source.html 为原设计，adapter.js 绑定状态，node build.mjs 生成 phone.js。protocol.js/text-state.js 定义变量协议，chat-protocol.js 校验聊天身份，phone-memory.js 组织共享时间线，stickers.js 保存本地图库。npm test 检查协议与状态；tests/v6.cjs 验证组件与预览确认；tests/v7.cjs 验证语音和跨聊天记忆；tests/v8.cjs 验证设置布局与表情包；tests/presets.cjs 验证预设。

### 0.9.0
- 兼容正文把空地写作“空地｜未知”的情况；支持连续格号如 1-15，播种不会被误判成熟。
- 输入框右侧：纸飞机只发气泡，对话气泡按钮让对方回复；语音、图片、表情包在下方工具栏。
- 表情包库在输入框下方展开，点选发送，＋导入；支持本地图片和已有图床图片直链（不代传到第三方图床服务）。
- 照片/截图独立发送，发送前可写说明。设置中开启“图片与表情包视觉识别”后，近期最多4张图片按需发给当前API；文字模型仅参考说明。
- 本地媒体保存在当前浏览器，聊天存档保存引用与说明；换设备需要重新导入媒体。图床链接需持续有效且允许外部访问。
