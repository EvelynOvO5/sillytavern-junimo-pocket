# Junimo Pocket 0.16.0

动物 App 支持幼崽成长、七种动物的生产周期、友谊与心情、干草扣料、领取产物和自定义动物。按游戏日期与时间结算；随正文楼层回退，新聊天独立。鸡舍/畜棚的具体心情系数采用用户给定范围内固定值；每日运气暂为0、松露简化为晴天户外每天最多1份，职业与加热器需按故事实际设置。

- 兼容手机正文中省略任务进度、目标折行等写法，保留目标、奖励与截止时间。
- 忽略柏宝绘图片标签、图片回填和图片渲染事件带来的同楼重复更新；正文、变量或候选实际改变仍重新同步。
- 修复农田计划中的空格误报，冻结本轮行动；正文数量不一致时保留操作，在行动篮核对，确认后校正农田和种子消耗。
- 区分取消、超时与无法取得 HTTP 状态的网络错误；新增请求诊断、30–600 秒超时设置及本楼主动消息精简重试。不会自动重复付费请求。

## 0.15.0

- 正文重生成或切换候选时回到该楼层之前的手机进度，再读取新正文。新快照同时记录消息、信件、动态评论、交易、任务、献祭和图鉴；API、提示词和头像设置保留。升级前的旧楼层没有完整进度快照，保留其独立手动记录，正文所属记录仍会更新。
- 各个私聊与群聊可先发送虚拟气泡，再从任一聊天点「真正发送」，所有待回复窗口合并一次 API 请求。各自回复、可选动态和评论在同一次返回中处理，保持身份与可见范围约束，不额外串行请求。输出上限仍遵循设置，较多聊天可提高上限。
- 聊天标题栏 ↻ 重 roll 最近一轮合并回复；邮件区分「收新信」与「重 roll」。新结果完整验证成功才替换本轮输出，失败保留旧结果；报错也可以重试。已推进到正文的回合、已领取赠送或接取委托不能重 roll，以免账目与故事矛盾。正文中已存在的信件由原正文管理，不在邮件重 roll 中改写。
- 手机操作自动注入正文上下文；行动篮不再向输入框粘贴长文。相邻同类农田动作按格号范围压缩，保留动作顺序；领取红包、赠礼、委托和献祭按已结算记忆处理，不重复加减。
- 完整【手机状态】…【状态结束】以及旧 junimo-state 在正文显示层隐藏，原始聊天和变量解析保持完整；进入酒馆消息编辑仍能检查原文。



本版将聊天与信件完整提示词放入各自 App 设置，可逐项编辑、保存和恢复默认；旧版额外来信偏好继续保留。聊天新增固定底部「消息 / 朋友圈」切换。红包采用粉色花间封面与金额预览，送礼采用鼠尾草绿礼物页。聊天设置改为独立页面，群成员可单独更换头像或跟随各自私聊头像。朋友圈支持本地上传个人头像和封面、修改头像左侧的公开 ID；改名后仍对应同一用户。

头像和封面图片保存在当前浏览器，个人资料与群头像按酒馆对话存档保存。提示词设置属于全局扩展设置，下一次生成生效；{{变量}} 会自动填入上下文。JSON 格式、角色身份以及交易合法性仍由解析器校验，修改提示词不会直接改动金币或物品。

更新时请完整替换扩展文件，尤其不要遗漏新增的 app-prompts.js；刷新酒馆后生效。构建：npm run build。测试：npm test。


SillyTavern 悬浮手机扩展，保留原版 HTML 的像素风界面、农场装饰、日历卡片、任务详情弹窗与全屏分区地图。

## 使用

从酒馆扩展管理更新本插件并刷新。打开月亮谷物语单角色聊天，开启手机设置中的“正文变量同步”，重新生成一轮正文让协议生效。旧正文没有变量块时不会使用 API 猜测。编辑、删除、切换正文后按快照回退。

首次升级到 0.5 会将旧版状态备份到本聊天元数据的 legacyBackup，采用空基线等待新的正文变量；手机聊天记录保留。

首次绑定只接受当前卡关联的世界书“⭐农民也要涩涩！”，之后跟随同一张卡的世界书，不混入全局世界书。手机聊天请求前读取最新内容。

API 设置在手机内：填写地址和 Key，拉取模型选择完整渠道名，保存多个命名预设并切换。HTTP 接口需勾选允许 HTTP，会明文传输 Key 和内容。预设 Key 存在当前浏览器 localStorage，同源脚本可访问；不进入 GitHub 或聊天存档导出。接口需允许浏览器跨域，503 表示所选服务或模型渠道暂不可用。

文字摘要使用固定栏目和分隔符，兼顾可读性与直接捕捉。变量协议降低误读，但生成模型仍可能写错，不是完整游戏规则引擎。行动是否执行及配方消耗以正文确认结果为准。

## 开发

source.html 为原设计，adapter.js 绑定状态，node build.mjs 生成 phone.js。protocol.js/text-state.js 定义变量协议，chat-protocol.js 校验聊天身份，phone-memory.js 组织共享时间线，stickers.js 保存本地图库。npm test 检查协议与状态；tests/v6.cjs 验证组件与预览确认；tests/v7.cjs 验证语音和跨聊天记忆；tests/v8.cjs 验证设置布局与表情包；tests/presets.cjs 验证预设。
