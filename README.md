# Junimo Pocket · 月亮谷手机

SillyTavern 前端扩展，保留原有月亮谷手机设计。通过酒馆的「扩展 → 安装扩展」安装，无需把整份 HTML 放进角色卡或每轮提示词。

## 0.2.0 更新

去掉手机外侧面板和标题栏；收起时显示指定小猫图片，展开只显示手机本体。API 设置成为手机桌面的「设置」App。点击右上角小箭头收起，按住手机顶端状态栏拖动，点击屏幕底部横条返回桌面。

自动读取当前月亮谷角色卡的主世界书「⭐农民也要涩涩！」，第一次成功读取后按角色卡头像文件标识绑定。以后世界书重命名也跟随这张卡的主世界书绑定。切换到其他角色卡或群聊会暂停后台请求，不读取全局/用户/聊天世界书，不读取编辑器里偶然选中的其他书。每次手机聊天或正文提取前都重新从酒馆读取已保存内容，修改世界书后无需复制人设，也无需刷新手机。

只读取启用条目，优先当前联系人和相关关键词、通用规则，排除状态栏脚本与思维链。此筛选专供手机，不复刻酒馆全部世界书触发算法；默认最多携带 18000 字符，超限会在设置内提示，长度可以调整。世界书仅作为背景数据，不执行其中脚本。

## 安装

仓库地址：**https://github.com/EvelynOvO5/sillytavern-junimo-pocket**

1. 在酒馆扩展面板点击「安装扩展」，粘贴上面地址。
2. 安装后刷新酒馆，打开月亮谷角色对话，点击小猫图标。按住图标或手机顶端状态栏可以拖动。
3. 打开手机桌面的「设置」，填写 OpenAI 兼容 API 的基础地址（例如 `https://你的服务商/v1`）、模型名和 Key。点击「检查世界书连接」确认绑定。
4. 「测试连接」成功后，勾选「正文自动同步」，按需启用主动消息，然后保存。
5. 点聊天 App，选联系人即可聊天。13 位联系人沿用原设计；具体性格自动从绑定世界书选取。

不要同时运行原 HTML 的悬浮挂载脚本，否则会出现两个手机。

## 能做什么

- 正文生成结束后，一次后台请求同时提取状态变化和适合当前情节的主动消息。
- 更新逐格农田（作物、成熟天数、浇水、肥料）、背包、金币、容量、日历、好感、任务、动物、角色地图位置和农场笔记。
- 在原聊天 App 内发送真实 API 请求；历史按角色分别保存在当前酒馆聊天中。
- 每段酒馆对话保存自己的世界状态、行动草稿和手机记录；刷新后恢复。
- 编辑、删除、切换 swipe 后，从首次变化处回退并重新提取；同一消息签名不会重复结算。
- 手机行动篮生成文字放入酒馆输入框，由你发送。农田点击是待执行预览，实际状态在后续正文确认后结算。
- JSON 状态校正、存档导出、校正前单次备份恢复。Key 不进入存档、角色卡或 GitHub。

## API、成本和数据范围

这是纯前端可安装扩展，使用 `/chat/completions`。API 服务必须允许来自酒馆网页的浏览器跨域请求（CORS）。不兼容的服务会明确报错；扩展不会绕过浏览器安全限制。HTTPS 酒馆应连接 HTTPS API，本机 HTTP API 支持 localhost/127.0.0.1。

未保存预设的 Key 仅存在当前网页内存中。保存 API 预设后，地址、Key、模型会写入当前浏览器的 localStorage，刷新后恢复已选预设；同源脚本可以访问，请勿在共享设备保存。地址、模型、开关和角色卡绑定标识保存在酒馆扩展设置，可能随酒馆设置备份。

启用时会把最近正文、当前世界状态、最近手机消息摘要，以及当前绑定角色卡的世界书相关条目发送到你指定的 API。不读取其他角色卡或全局世界书，不读取酒馆预设和主模型隐藏上下文。

首次启用仅从最新一条角色正文开始，不付费重放整个聊天历史。初始金币、物品和农田取自原预览设计，不代表你的实际存档；建议首次在设置校正。后续每个完成的角色回合通常一次请求；手动手机聊天每次一次请求；改写历史会重算受影响的后续回合。默认正文上限 12000 字符，手机历史 16 条，输出 2200 tokens，可调整。手机 HTML/CSS 不进入模型输入。

正文里未明确发生的事情要求保持原值，不自动跨天；提取仍依赖模型理解，遇到歧义可用状态校正。JSON 校验失败、超时或 HTTP 错误不会写入半份新状态，可在设置重试。

## 状态校正示例

设置中的状态编辑器预填完整当前状态，修改所需值后应用。数组是完整替换：`inventory: []` 表示清空背包，`plots` 第一个元素就是第 1 格。

```json
{
  "gold": 500,
  "calendar": {"season":"春季","day":2,"time":"08:00","weather":"晴"},
  "inventory": [{"name":"防风草种子","count":15,"price":20,"kind":"seed","days":4}],
  "plots": [{"crop":"防风草","days":3,"wet":true,"fertilizer":""}],
  "relationships": {"01":250},
  "quests": [{"name":"初次播种","status":"进行中"}]
}
```

角色人设直接在酒馆绑定的世界书里维护，手机不需要重复填写。

## 当前边界

- 建筑商店和制作配方仍是原设计的操作模板，材料与建造结果由正文演绎确认；实际建筑变化记录在农场笔记。不是完整星露谷规则引擎。
- 手动手机聊天作为独立通信保存，删改正文会回退关联的主动消息，不删除手动通信历史。
- 原设计的头像、背景和图标仍由外部图床提供；图床不可用时会显示颜色/文字后备效果。
- 目前验证了模拟酒馆上下文与 API 响应；真实服务商的 Key、CORS 和模型输出表现需在自己的酒馆连接测试。

`manifest.json`、`index.js`、`core.js`、`lore.js`、`phone.js` 为安装所需文件。`source.html` 是用户提供的原设计，`adapter.js` 为状态/聊天连接层。

```sh
npm test
npm run build
```
