# Junimo Pocket · 月亮谷手机

SillyTavern 悬浮手机扩展，保留原版 HTML 的像素风界面、农场装饰、日历卡片、任务详情弹窗与全屏分区地图。

## 0.5.0

- 正文负责变量：自动注入变量协议，每轮正文末尾生成 `<junimo-state>{"version":1,"patch":{…}}</junimo-state>`，手机校验后直接读取，不再调用独立 API 推测状态。
- 首次变量块包括全部角色的初始地图位置，之后只更新移动角色，直接在原版地图标记头像。
- 农田区分 empty、seeded、growing、mature。未成熟作物不能写成剩余 0 天，未知天数用 null。变量缺失或无效时明确提示。
- 开局背包、动物、建筑、材料、种植为空，装饰图片仍保留。
- 独立 API 仅负责手机私聊和随正文产生的主动消息，角色知道这是手机文字聊天，支持多条短气泡。
- 虚拟发送：立即形成气泡，不调用 API，可连续发送多条。真正发送：把当前输入及待回复气泡交给角色统一回复；失败保留气泡，可重试。
- 从灵动岛、状态栏或边框拖动，右上收起按钮在每个 App 内可用。

## 使用

从酒馆扩展管理更新本插件并刷新。打开月亮谷物语单角色聊天，开启手机设置中的“正文变量同步”，重新生成一轮正文让协议生效。旧正文没有变量块时不会使用 API 猜测。编辑、删除、切换正文后按快照回退。

首次升级到 0.5 会将旧版状态备份到本聊天元数据的 legacyBackup，采用空基线等待新的正文变量；手机聊天记录保留。

首次绑定只接受当前卡关联的世界书“⭐农民也要涩涩！”，之后跟随同一张卡的世界书，不混入全局世界书。手机聊天请求前读取最新内容。

API 设置在手机内：填写地址和 Key，拉取模型选择完整渠道名，保存多个命名预设并切换。HTTP 接口需勾选允许 HTTP，会明文传输 Key 和内容。预设 Key 存在当前浏览器 localStorage，同源脚本可访问；不进入 GitHub 或聊天存档导出。接口需允许浏览器跨域，503 表示所选服务或模型渠道暂不可用。

变量协议降低误读，但生成模型仍可能写错，不是完整游戏规则引擎。行动是否执行及配方消耗以正文确认结果为准。

## 开发

source.html 为原设计，adapter.js 绑定状态，node build.mjs 生成 phone.js。protocol.js 定义正文变量和手机气泡格式。npm test 检查协议与状态；tests/v5.cjs 验证原版组件、播种、地图头像、任务弹窗、气泡、收起与拖动；tests/presets.cjs 验证预设。
